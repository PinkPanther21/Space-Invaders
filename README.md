# 🚀 Space Invaders: 90s Style

A retro arcade space shooter that runs in the browser, built with HTML, CSS and vanilla JavaScript. Created for [HACKATHON NAME], a retro-themed web hackathon.

### 🎮 [Play it live](https://pinkpanther21.github.io/Space-Invaders/)



## Features

- 90s arcade look with a retro menu and loading screen
- Sound effects for shooting, hits and game over
- High score table
- Separate About, Info and Comments pages
- Runs fully in the browser, no installation needed

## Controls

| Key | Action |
|-----|--------|
| [KEY] | Move left / right |
| [KEY] | Shoot |

## Tech Used

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)
- Hosted on GitHub Pages

## Run Locally

1. Clone the repo:
```
   git clone https://github.com/PinkPanther21/Space-Invaders.git
```
2. Open `index.html` in your browser.
